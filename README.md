## 🎯 项目背景
在热工仪表、工业自动化现场作业中，从业者普遍面临以下核心痛点：
1. **便携性不足**：传统桌面端热工计算软件、专业校验工具无法满足现场移动作业需求，户外/设备端计算效率极低
2. **精度无保障**：手动查表、普通计算器计算存在人为误差，浮点数运算精度不足，易导致校准结果偏差
3. **标准不统一**：不同厂家、不同工具的热电偶/热电阻计算标准不统一，部分工具仍使用老旧温标，与国际法定计量标准脱节
4. **功能碎片化**：现场作业需要同时携带温度计算、压力校验、单位换算等多个工具，数据无法互通，操作流程繁琐
5. **数据追溯难**：手动记录校验数据、计算结果易丢失，无法快速回溯历史作业记录，不符合工业现场数据留存要求

本项目基于微信小程序生态，打造了一款**全功能、高精度、标准化、可离线使用**的工业热工工具，彻底解决上述行业痛点，为热工仪表从业者提供开箱即用的专业计算方案。

## ✨ 核心特性
### 🔧 专业级热工计算能力
- 支持**8种主流热电偶**、**3种工业常用热电阻**的双向高精度计算，严格遵循ITS-90国际温标与IEC 60751标准
- 内置热电偶冷端温度自动补偿功能，适配现场无恒温冷端的作业场景
- 全量程范围自动校验，超出传感器有效量程实时预警，避免无效计算
- 基于decimal.js实现全链路高精度十进制计算，彻底解决JavaScript浮点数精度丢失问题

### 📊 标准化压力校验系统
- 双模式校验：支持**弹簧管式压力表**、**智能压力变送器（4-20mA）** 两大工业核心场景
- 自动生成校验方案：基于量程与精度等级，一键生成5点标准校验序列，符合国家计量检定规程
- 全参数自动计算：自动计算允许误差、上行示值误差、下行示值误差、回程误差，实时判定校验结果是否合格
- 校验记录全留存：完整保存仪表信息、校验环境、校验数据、结果判定，支持历史记录一键复用与导出

### 📐 多场景单位换算工具
- 覆盖工业现场全场景单位换算：**压力单位6种**、**温度单位3种**、**CEMS烟气浓度换算**
- 内置标准换算公式，无需手动查表，输入即得结果，支持双向实时换算
- 适配环保监测场景，内置SO₂、NOₓ、NO等主流烟气组分摩尔质量，一键完成ppm与mg/m³的标准状态换算

### 💾 智能化数据管理
- 本地持久化存储：自动保存计算历史、校验记录、用户个性化设置，小程序重启后数据不丢失
- 历史记录上限管理：最多支持50条历史记录自动轮转，避免存储溢出
- 一键恢复功能：支持从历史记录快速恢复计算状态，无需重复输入参数，提升重复作业效率
- 个性化配置：支持自定义温度、压力计算结果小数位数，开关振动提醒功能，适配不同用户使用习惯

### 📱 极致的移动端体验
- 全离线可用：核心计算逻辑完全本地化，无网络环境下仍可正常使用，适配工业现场弱网场景
- 操作极简：针对移动端单手操作优化，输入参数实时计算，无需额外点击确认
- 错误反馈机制：输入超限、校验不合格时触发振动提醒（可配置），避免人为失误
- 全平台兼容：适配微信全版本、全尺寸移动端设备，无兼容性问题

## 📚 功能详解
### 1. 温度转换模块（核心功能）
#### 支持传感器类型与量程
| 传感器类型 | 型号 | 有效量程范围 | 执行标准 |
|------------|------|--------------|----------|
| 热电偶 | K型（镍铬-镍硅） | -200℃ ~ 1372℃ | ITS-90国际温标 |
| 热电偶 | E型（镍铬-铜镍） | -200℃ ~ 1000℃ | ITS-90国际温标 |
| 热电偶 | S型（铂铑10-铂） | 0℃ ~ 1768℃ | ITS-90国际温标 |
| 热电偶 | B型（铂铑30-铂铑6） | 200℃ ~ 1820℃ | ITS-90国际温标 |
| 热电偶 | R型（铂铑13-铂） | 0℃ ~ 1768℃ | ITS-90国际温标 |
| 热电偶 | J型（铁-铜镍） | -200℃ ~ 1200℃ | ITS-90国际温标 |
| 热电偶 | N型（镍铬硅-镍硅） | -200℃ ~ 1300℃ | ITS-90国际温标 |
| 热电偶 | T型（铜-铜镍） | -200℃ ~ 400℃ | ITS-90国际温标 |
| 热电阻 | Pt100 | -200℃ ~ 850℃ | IEC 60751:2008 |
| 热电阻 | Pt1000 | -200℃ ~ 850℃ | IEC 60751:2008 |
| 热电阻 | Cu50 | -50℃ ~ 150℃ | IEC 60751:2008 |

#### 核心计算能力
- **正向计算（温度→信号）**：输入被测温度值，自动计算对应热电偶热电势(mV)、热电阻电阻值(Ω)
- **反向计算（信号→温度）**：输入实测热电势/电阻值，自动计算对应被测温度值
- **冷端补偿**：热电偶模式下，输入现场冷端温度，自动完成冷端补偿计算，输出真实被测温度
- **量程校验**：实时校验输入值是否在对应传感器有效量程内，超出范围自动提示并禁止计算
- **精度控制**：支持用户自定义结果小数位数，默认保留4位小数，最高支持6位小数精度

### 2. 压力校验模块
#### 压力表校验模式
- 核心参数配置：支持输入仪表编号、仪表类型、量程上限、量程下限、精度等级、环境温度、相对湿度
- 自动计算：基于量程与精度等级，自动计算基本误差限、允许最大绝对误差
- 标准点生成：一键生成0%、25%、50%、75%、100%量程5个标准校验点，符合JJG 52-2013弹簧管式压力表检定规程
- 误差计算：自动计算每个校验点的上行示值误差、下行示值误差，自动判定是否合格
- 结果判定：基于所有校验点数据，自动判定整台仪表是否合格，生成完整校验记录

#### 压力变送器校验模式
- 兼容4-20mA标准信号输出的智能压力变送器，支持输入量程上下限、精度等级、输出信号范围
- 自动计算对应标准点的理论输出电流值，支持输入实测上行/下行电流值，自动计算示值误差、回程误差
- 支持零点迁移、量程迁移场景的校验计算，适配工业现场特殊安装工况
- 自动生成完整校验记录，包含变送器基本信息、校验环境、全点数据、结果判定

### 3. 单位换算模块
#### 压力单位换算
- 支持单位：MPa、bar、psi、kPa、mmHg（毫米汞柱）、atm（标准大气压）
- 换算基准：以国际标准单位MPa为基准，采用标准换算系数，确保换算精度
- 支持双向实时换算，输入任意单位数值，自动同步更新所有单位结果

#### 温度单位换算
- 支持单位：摄氏度(℃)、华氏度(℉)、开尔文(K)
- 内置标准换算公式，支持全范围双向换算，适配工业现场不同标准的温度标注场景

#### CEMS气体浓度换算
- 核心功能：ppm与mg/m³的标准状态下双向换算，适配环保监测、烟气排放检测场景
- 内置组分：SO₂、NOₓ、NO等主流烟气污染物，内置标准摩尔质量参数
- 换算公式：严格遵循国标规范 `mg/m³ = ppm × 摩尔质量 / 22.4`，支持自定义摩尔质量适配特殊组分

### 4. 个人中心模块
- 历史记录管理：查看、删除、清空所有温度计算、压力校验历史记录，支持一键恢复计算状态
- 个性化设置：自定义热电偶/热电阻/压力计算结果的小数位数，开关振动提醒功能
- 数据持久化：所有设置与记录均存储于微信小程序本地存储，无需登录账号，开箱即用
- 版本信息：展示小程序当前版本、更新日志、标准依据等信息

## 🚀 快速上手
### 前置要求
- 微信开发者工具：Stable 1.06+ 版本（[下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)）
- 微信小程序账号：已注册微信小程序账号，并获取AppID（个人/企业主体均可）
- 基础环境：Windows/macOS 操作系统，可正常访问微信开放平台

### 安装与部署步骤
1. **克隆仓库到本地**
```bash
git clone https://github.com/Cavalcdor/thermal-assistant.git
cd thermal-assistant
```

2. **配置小程序AppID**
   - 打开项目根目录下的 `project.config.json` 文件
   - 找到 `appid` 字段，将默认值替换为你的微信小程序AppID
   ```json
   {
     "description": "项目配置文件",
     "packOptions": {
       "ignore": []
     },
     "setting": {
       "urlCheck": false,
       "es6": true,
       "enhance": true
     },
     "appid": "你的小程序AppID",
     "projectname": "thermal-assistant",
     "condition": {}
   }
   ```

3. **导入项目到微信开发者工具**
   - 打开微信开发者工具，选择「小程序」-「导入项目」
   - 选择项目根目录，填写项目名称与AppID，点击「确定」导入
   - 工具会自动加载项目依赖与配置，完成项目初始化

4. **本地调试与预览**
   - 导入完成后，开发者工具会自动编译项目，在模拟器中展示小程序界面
   - 可直接在模拟器中测试所有功能，验证计算逻辑与界面交互
   - 点击工具栏「预览」按钮，扫码即可在手机微信中真机调试

5. **发布上线**
   - 完成功能测试与调试后，点击工具栏「上传」按钮，填写版本号与项目备注，上传代码到微信公众平台
   - 登录微信公众平台，进入小程序管理后台，在「版本管理」中提交代码审核
   - 审核通过后，点击发布，即可正式上线使用

## 🛠️ 技术栈与算法标准
### 核心技术栈
| 技术/依赖 | 版本 | 用途说明 |
|-----------|------|----------|
| 微信小程序原生框架 | 基础库2.0+ | 项目核心开发框架，全平台兼容 |

| 微信小程序振动API | - | 操作反馈与错误提醒 |

### 执行标准与算法依据
1. **温度计算标准**：
   - 热电偶：ITS-90国际温标（1990年国际温标），采用标准分度表多项式拟合算法
   - 热电阻：IEC 60751:2008 工业铂热电阻国际标准，对应国标JJG 229-2010
2. **压力校验标准**：
   - 压力表：JJG 52-2013 弹性元件式一般压力表、压力真空表和真空表检定规程
   - 压力变送器：JJG 882-2019 压力变送器检定规程
3. **单位换算标准**：
   - 压力单位：GB 3100-1993 国际单位制及其应用
   - 烟气浓度换算：HJ 75-2017 固定污染源烟气（SO₂、NOₓ、颗粒物）排放连续监测技术规范

## 💻 开发指南
### 本地开发规范
1. **代码规范**：遵循JavaScript ES6+ 语法规范，使用分号结尾，采用2空格缩进，变量命名采用小驼峰式，常量采用全大写下划线分隔
2. **页面开发规范**：每个页面独立封装，页面逻辑与通用算法分离，通用计算逻辑必须封装在`utils/`目录下，禁止在页面js中硬编码核心算法
3. **样式规范**：全局通用样式定义在`app.wxss`中，页面独有样式定义在页面对应wxss文件中，采用rpx单位适配不同屏幕尺寸
4. **存储规范**：所有本地存储操作必须通过`utils/storage.js`封装的方法执行，禁止直接调用wx.setStorageSync/wx.getStorageSync，便于统一管理

### 核心算法扩展
如需新增热电偶/热电阻型号，按以下步骤执行：
1. 在`utils/thermocouple.js`（热电偶）或`utils/rtd.js`（热电阻）中，新增对应型号的分度表多项式系数、量程范围
2. 新增对应型号的正向/反向计算方法，遵循现有代码的封装规范
3. 在`pages/thermal/thermal.js`中的传感器类型列表中，新增对应型号选项
4. 在`minitest/`目录下，新增对应型号的单元测试用例，验证计算精度符合标准
5. 完成测试后，提交PR合并代码

### 调试与测试
- **本地调试**：使用微信开发者工具的模拟器进行功能调试，开启「调试模式」查看console日志与网络请求
- **真机调试**：使用微信开发者工具的「真机调试」功能，在手机端进行真机测试，验证振动、存储等手机权限相关功能
- **单元测试**：在`minitest/`目录下编写单元测试用例，覆盖核心算法的全量程范围，验证计算误差在允许范围内
- **兼容性测试**：测试不同微信版本、不同手机系统（iOS/Android）、不同屏幕尺寸的兼容性
